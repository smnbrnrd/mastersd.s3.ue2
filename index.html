Description et supports

Les supports ci-dessous sont proposés dans le cadre du cours « Web Dynamique côté Serveur » du Master Science des Données de l'Université de Rouen Normandie.

Ce cours est une introduction au développement d'applications web dynamiques côté serveur avec la plateforme Jakarta EE. Il couvre les concepts de bases, les API essentielles et introduit brievement le framework Spring.

Ce cours est divisé en 7 parties :

Lecture Titre Liens
1 Introduction Rappels sur le Web, serveurs web et d'application, plateforme Jakarta EE, architectures des applications web Slides PDF
2 Jakarta Servlet Le composant servlet, traitement des requêtes, cookies et sessions Slides PDF
3 Jakarta Server Pages Pages JSP, Expression Language, architecture MVC Slides PDF
4 Jakarta Contexts and Dependency Injection (CDI) Injection de dépendances, CDI managed beans, qualifiers, portées, intercepteurs, méthodes producer Slides PDF
5 Jakarta Faces Facelets, backing beans, convertisseurs et validateurs, cycle de vie, événements et navigation Slides PDF
6 Jakarta REST Architecture orientée services, services web RESTful, annotations JAX-RS, data binding, API client Slides PDF
7 Le framework Spring Introduction au framework Spring (à venir) Slides PDF
